# Research returns

Drop completed deep-research output here, one file per brief
(`R1-engine-short-block.md`, `R12-fasteners.md`, …), in the standard
return format described in `../RESEARCH-BRIEFS.md`.

Anything landed here gets converted into part records in
`src/data/parts/*.json`, with sources preserved in the part descriptions
and `UNVERIFIED.md` updated as nulls are replaced by real data.
