Facts these photos settled (all applied to the model):
- Engine is INTAKE-FORWARD; turbo at the rear (confirmed).
- Coolant expansion tank: OFFSIDE front corner (I had it wrong twice).
- Screen-wash filler: OFFSIDE, inboard of the coolant tank (wrong twice).
- Battery: NEARSIDE mid-bay in a felt jacket, fuse box directly behind it.
- Intake: aftermarket RACINGLINE system, not the stock 5Q0129607AC airbox.
- PCV module: mid-cover, coils behind it, HPFP right, filler cap left.
- Brake reservoir: offside rear, behind the coolant tank.
